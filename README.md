# Paklijst v3.1

Persoonlijke, offline-first paklijst voor GitHub Pages.

## v3.1 — iPhone / iPad
- Werkt als normale website én als installeerbare PWA op iPhone/iPad
- Bij eerste gebruik wordt automatisch een eerste reis met de masterlijst aangemaakt
- Duidelijke "Backup importeren" en "Backup delen" flow
- JSON-backup van masterlijst + alle reizen
- Backup kan via de iOS Deel-knop naar Bestanden, WhatsApp, Mail, AirDrop enz.
- Geen account, Firebase of backend nodig
- Bestaande v2/v3 lokale gegevens blijven in dezelfde `paklijst-v2` opslag

## PC → iPhone
1. Open de app op de PC.
2. Ga naar **Mijn reizen**.
3. Kies **Backup delen** of gebruik **Volledige backup → JSON**.
4. Stuur het JSON-bestand naar je iPhone.
5. Open de Paklijst op je iPhone.
6. Kies **Backup importeren**.
7. Selecteer het JSON-bestand in Bestanden.
8. De masterlijst en je reizen staan daarna op de iPhone.

## iPhone als app installeren
Open de site in Safari → **Deel** → **Zet op beginscherm**.
Daarna opent Paklijst als een eigen app.

## Belangrijk
De app synchroniseert niet automatisch tussen apparaten. De data staat lokaal.
Maak daarom regelmatig een JSON-backup als je belangrijke wijzigingen hebt gemaakt.

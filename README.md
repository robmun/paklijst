# Paklijst PWA

Een eenvoudige, mobiele paklijst gebaseerd op de persoonlijke vakantielijst uit `paklijst(1).docx`.

## Functies v1
- Persoonlijke basislijst met de oorspronkelijke categorieën/items
- Reisnaam, vertrekdatum en reisduur
- Items afvinken
- Voortgang per reis
- Zoeken en filteren
- Items toevoegen, wijzigen en verwijderen
- Categorie kiezen
- Aantal/opmerking per item
- Printvriendelijke versie
- Offline PWA / toevoegen aan beginscherm
- Gegevens worden lokaal in de browser opgeslagen

## Installeren op GitHub Pages
Upload `index.html`, `manifest.json`, `sw.js` en `icon.svg` naar een repository en activeer GitHub Pages.
